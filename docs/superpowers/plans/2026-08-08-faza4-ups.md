**Files:** Modify `atlas/business/power.py`; Test `tests/test_power.py`.
**Interfaces:**
- `shutdown_plan(spine) -> list[dict]` — uređaji s `caps.shutdown_order` (ne-None) sortirani uzlazno (radnici prvo), server kao SINTETIČKI zadnji korak (lokalno gašenje). Uređaj bez hosta se preskače uz oznaku (nema kako ga ugasiti bez agenta — faza 5).
