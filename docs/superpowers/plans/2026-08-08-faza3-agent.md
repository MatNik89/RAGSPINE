### Task 1: Registar alata (agent_tools.py) nad business slojem
**Files:** Create `atlas/rag/agent_tools.py`; Test `tests/test_agent_tools.py`.
**Interfaces produces:**
- `TOOLS: dict[str, Tool]` gdje Tool = {name, description, schema(dict), readonly(bool), min_role(str), run(spine,cfg,actor,args)->dict}.
- `validate(name, args) -> (ok: bool, error: str|None)` — schema + domenska provjera (oib_valid, datum ISO, obavezna polja).
- `allowed(actor, tool) -> bool` — min_role + (za klijentske alate) vidljivost.
- `run_tool(spine, cfg, actor, name, args) -> dict` — validate+allowed pa poziv business funkcije; nepoznat/nedopušten → ValueError.

Alati (pozivaju POSTOJEĆE: onboarding.create_client, onboarding/clients upit, obveze.mark_sent + upiti, expiry.add, notes.add, pipeline.answer/retrieval.search, websearch.ddg/handle):
- readonly: `pretrazi(upit, web:bool=False)`, `popis_obveza(filter)`, `stanje_klijenta(kljuc)`
- write: `dodaj_klijenta`, `uredi_klijenta`, `oznaci_obvezu`, `zakazi_rok`, `zapisi_belesku`

- [ ] Step 1: testovi (validate odbija loš OIB / nepostojećeg klijenta / krivi datum; allowed po roli+vidljivosti; run_tool readonly vraća podatke; write run_tool poziva business s točnim argumentima kroz mock/spine; nepoznat tool → ValueError).

### Task 3: Agentska petlja (agent.py)
**Files:** Create `atlas/rag/agent.py`; Test `tests/test_agent.py`.
**Interfaces produces:**
- `run_agent(spine, cfg, query, actor, llm, max_steps=4) -> dict` → {text, sources, pending: {tool, args, summary} | None}. Pending = prva write akcija (petlja stane, čeka potvrdu). Read-only alati se izvrše u petlji i rezultat vrati LLM-u. Bez tool_calla = text finalni.
- `summarize_action(name, args) -> str` — ljudski hrvatski sažetak za potvrdu ("Dodat ću klijenta X (OIB ...)").
- system prompt (hrvatski) opisuje ulogu/alate/pravilo potvrde.

- [ ] Step 1: testovi (lažni llm skriptira tool_calls: read-lanac pa finalni text; write→pending prekid s validiranim argumentima; nevažeći write arg → LLM dobije grešku i može ispraviti; max_steps stop; nepoznat tool ignoriran uz poruku).
- [ ] Step 2: FAIL.
- [ ] Step 3: implementacija (petlja poziva llm.complete s tools=agent_tools schema; dispatch po readonly; pending build).
- [ ] Step 4: run + puni suite.
