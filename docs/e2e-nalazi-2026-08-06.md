### PATH osvježavanje bez restarta terminala
- Nakon winget instalacije (Tesseract) wizard traži restart terminala jer proces
  drži staru kopiju PATH-a. Dorada: (a) nakon instalacije ponovno pročitati PATH
  iz registryja (HKLM/HKCU Environment) i osvježiti os.environ pa "Provjeri
  ponovno" radi bez izlaska; (b) fallback probe na poznate lokacije
  (`C:\Program Files\Tesseract-OCR\tesseract.exe` itd.).

### Tesseract auto-install nepotpun (KRITIČNO za doradu)
- UB-Mannheim winget paket NE dodaje PATH (ni novi terminal ne pomaže — poruka
  "restartaj terminal" je kriva dijagnoza) i NE nosi hrv jezik (tessdata ima
  samo eng+osd, a preflight traži hrv+eng pa provjera trajno pada).
- Dorada auto-installa: (a) nakon instalacije sam skini
  `hrv.traineddata` (github tesseract-ocr/tessdata) u tessdata mapu;
  (b) dodaj `C:\Program Files\Tesseract-OCR` u user PATH ili koristi punu
  putanju; (c) ponuda ponovne instalacije mora reći "već instalirano" umjesto
  da opet vrti winget.
- Na probi ručno odrađeno preko SSH (hrv.traineddata + user PATH).

### Pull ignorira izračunatu kvantizaciju (BUG, stranica 3)
- Lista prikazuje llmfit kvantizaciju (npr. qwen2.5:7b Q2_K ~3,8 GB), ali pull
  vuče goli tag (`ollama pull qwen2.5:7b`) = default kvant s registryja
  (tipično Q4_K_M, ~4,7 GB) — obećani i stvarni footprint se razilaze, model
  koji "stane" možda NE stane. Dorada: pull taga s kvant sufiksom
  (npr. `qwen2.5:7b-instruct-q2_K`) kad postoji, uz fallback + upozorenje kad
  registry nema taj kvant; nakon pulla usporediti stvarnu veličinu s obećanom.
