## Popravljeno tijekom probe

1. **install.ps1 bez UTF-8 BOM-a** — PowerShell 5.1 čita .ps1 bez BOM-a kao ANSI,
   `✓`/`—` postanu smeće i parser pukne. Fix: BOM (commit 1c27564).
2. **PS 5.1 + EAP=Stop + stderr kroz `2>$null` = terminirajuća greška** —
   `Find-Python` je umirao na prvom py kandidatu (3.13 neinstaliran) umjesto da

### `ragspine upgrade` naredba (korisnikov zahtjev s probe)
- Jedan korak za ured: verificirani backup → `git pull` → `pip install -e .`
  po potrebi (promjena ovisnosti) → restart servera → ispis "što je novo".
- ROLLBACK ugrađen: prije pulla zapamti trenutni commit (last-known-good);
  `ragspine upgrade --rollback` = checkout tog commita + restart; ako je
  problem u bazi, `ragspine restore <backup od prije nadogradnje>`.
  Migracije držati ADITIVNIMA (samo dodavanje stupaca/tablica) da stari kod
  radi i s novijom bazom.
- Uz to uvesti TAGIRANE verzije (v1.0.0...) — uredski stroj prati tagove,
  ne goli master; "verzija prije" onda ima ime.
